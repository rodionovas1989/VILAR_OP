# D011 — Порядок выпуска партии (sequence), не парсинг в FEFO

**Контекст:** У собственных партий одна календарная дата / срок, но разный номер загрузки (`900726` раньше `910726`, загрузка может быть >99). Закупные номера (`CAST4P2001`) ту же маску не несут.

**Решение:** каноническое поле `lot.productionSequence`. Компаратор FEFO/FIFO: дата(ы) → sequence → склад. Маска живёт в **модели учёта**, разбор на записи партии (справа налево для заводского пресета).

Не делать: regex в `availableLotsForMaterial`, третий алгоритм, привязку к имени производителя.
