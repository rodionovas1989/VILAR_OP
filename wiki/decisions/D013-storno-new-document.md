# D013 — сторно = новый документ

**Решение:** отмена проведённого складского документа, двигающего остаток, выполняется как в SAP MM IM:

1. Создаётся **новый** документ-сторно B (черновик → пользователь проводит).
2. B содержит обратные количества и ссылку на исходник A (`reverses_document_id` ≈ SMBLN).
3. A остаётся в истории; после полного сторно — статус `reversed`.
4. Учётная дата движения — `postingDate` (≈ BUDAT); техническое время — `at` (≈ CPUDT). У B по умолчанию `postingDate` как у A.

**Не делаем:** тихое автопроведение B; пометку всех строк одного `documentId` как `cancelled` с обратными дельтами внутри A (legacy).

**MVP:** полное сторно (R10). Частичное по строкам — R11.
