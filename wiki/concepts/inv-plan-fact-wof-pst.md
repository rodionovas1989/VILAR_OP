# Concept: INV план/факт → WOF/PST

Инвентаризация:

- План / Факт / Разница в UI.
- Факт `0` / мусор не должен молча удалять строку (DecimalInput + guards).
- Разница через `roundQty` (без float-хвостов).
- Проведение INV → черновики списания/оприходования; остатки меняют уже они.
