# Concept: одна партия сырья на компонент в серии

**Смысл:** в одной серии ГП (один заказ) для каждого компонента спецификации — **не больше одной** партии сырья.

**Зачем:** прослеживаемость, расследования, отзыв; срок годности смеси по самой «старой» партии — при одной партии риск ниже.

**В системе:**

- Подбор сырья выбирает одну партию на материал заказа.
- Две партии одного материала на заказ зарезервировать нельзя.
- Смешивание партий в рамках серии ГП **не поддерживается**.
