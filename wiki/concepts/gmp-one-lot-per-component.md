# Concept: одна партия сырья на компонент в серии

**Смысл:** в одной серии ГП (один заказ) для каждого компонента спецификации по умолчанию — **не больше одной** партии сырья.

Если в модели учёта материала включено «Смешение партий одного производителя», допускаются **несколько партий с одним производителем** (несколько строк в заказе). Разные производители — нет; явные пары номеров — будущий справочник качества ([lot-mixing-policy](../analyses/lot-mixing-policy.md)).

**Зачем:** прослеживаемость, расследования, отзыв; срок годности смеси по самой «старой» партии.

**В системе:**

- Подбор сырья выбирает одну партию на материал заказа, либо несколько одного производителя при тогле модели.
- Две партии одного материала на заказ без тогла зарезервировать нельзя.
- Правило про **партию** (`lotId`), не про «одну ячейку склада». Если одна партия разнесена по складам и на одном месте не хватает qty — сейчас нужно **перемещение (TRN)** на склад списания; авто-сплит одной партии по складам отложен ([D010](../decisions/D010-same-lot-multi-warehouse.md)).
