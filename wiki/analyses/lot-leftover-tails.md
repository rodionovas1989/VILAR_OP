# Analysis: «хвосты» партий после FEFO/FIFO

**Проблема:** мелкие свободные остатки партии никогда не набирают need целой серии → алгоритм их обходит → партия «висит» до истечения срока.

**Не путать с:** нехваткой при пакетном подборе (это закрыто виртуальным claimed в `suggestPicksBulk`).

**UX (готово):** кнопка «Хвосты партий» на вкладке подбора → модалка: партии с `freeQty > 0`, которые для материалов текущей выборки **ни разу не выбраны**, потому что `free < maxNeed` по строкам подбора. Мягкая подсказка: TRN / утилизация / меньшая серия. Без авто-утилизации и без нарушения GMP «одна партия на компонент».

**API:** `POST /planning/lot-leftover-tails` (`leftoverLotTails`).

**Статус:** готово (ROADMAP G9).
