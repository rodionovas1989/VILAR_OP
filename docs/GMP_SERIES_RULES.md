# Правила обращения с сериями и партиями (GMP) — рабочая выжимка для планирования

Документ описывает правила, которые система оперативного планирования обязана учитывать при резервировании сырья под серию готовой продукции.  
Источники: Правила GMP ЕАЭС (Решение Совета ЕЭК от 03.11.2016 № 77), Приказ Минпромторга РФ № 916, PIC/S PE 009, WHO/ICH Q7 (для АФС).  
**Документ черновой — подлежит корректировке заказчиком.**

---

## 1. Термины

| Термин | Значение в системе |
|--------|--------------------|
| **Серия (batch) готовой продукции** | Уникальный идентификатор выпуска ЛП; объект `series` / поле серии в заказе на производство |
| **Партия (lot) сырья** | Уникальный идентификатор поставки/выпуска исходного материала; объект `lots` |
| **Спецификация / рецептура** | Утверждённый состав (BOM): норма расхода **кг на 1000 упаковок** |
| **Резерв** | Закрепление количества партии сырья за конкретной серией/заказом |

---

## 2. Идентификация и прослеживаемость

1. Каждая серия готовой продукции должна иметь **уникальный номер**, по которому восстанавливается история производства и контроля.
2. Каждая партия исходного сырья при приёмке получает **внутренний номер партии**; разные поставки / разные серии поставщика учитываются **раздельно**.
3. Если одна поставка содержит несколько серий поставщика — каждая серия учитывается, отбирается и отпускается **как отдельная партия** (EU GMP / GMP ЕАЭС, гл. 5 — исходные материалы).
4. Во всех производственных записях (в системе — заказ, резерв, движение) фиксируются: материал, **номер партии сырья**, количество, **номер серии ГП**.

---

## 3. Правило «одна партия сырья на один компонент в серии» (ключевое для планирования)

> При производстве **одной серии** готовой продукции для **каждого компонента** спецификации допускается использование **не более одной партии** сырья.

### Обоснование и следствия

- Смешивание разных партий одного компонента внутри одной серии ГП усложняет прослеживаемость, расследование отклонений и отзыв.
- Срок годности / дата повторного испытания смеси определяется по **самой «старой»** входящей партии (GMP ЕАЭС, разд. 8.4 для смешивания серий промежуточной продукции/АФС) — при одной партии на компонент риск минимален.
- В алгоритмах FEFO/FIFO система **не дробит** потребность по нескольким партиям, если это можно избежать; если одной партии не хватает — требуется явное решение пользователя (и в будущем — процедура смешивания/валидации).

### Реализация в системе

- Алгоритм подбора сырья (вкладка «Подбор сырья») для каждого материала заказа выбирает **одну** подходящую партию.
- Ручная замена партии разрешена, но **нельзя** зарезервировать две партии одного материала на одну серию/заказ.
- При подтверждении создаются записи резерва и строки табличной части заказа: `(материал, партия, количество)`.

---

## 4. Смешивание серий (GMP ЕАЭС / Приказ № 916, п. 8.4)

1. **Смешивание** — объединение веществ для получения однородной промежуточной продукции или АФС с **одной** спецификацией.
2. Объединение частей **одной** серии в ходе процесса (напр. несколько загрузок центрифуги) **не** считается смешиванием.
3. **Запрещено** смешивать серии, не соответствующие спецификации, «дотягивая» качество.
4. Каждая серия перед смешиванием должна быть произведена по утверждённой технологии, **испытана отдельно** и соответствовать спецификации.
5. Процесс смешивания документируется и контролируется; при критичных физ. свойствах — валидация однородности.
6. Срок годности / повторного испытания смеси — по **наиболее ранней** дате среди входящих серий.

В текущей версии ОП-системы смешивание партий сырья в рамках одной серии ГП **не поддерживается** (см. §3).

## 5. FEFO / FIFO и годность

| Алгоритм | Правило сортировки доступных партий |
|----------|-------------------------------------|
| **FEFO** (First Expired — First Out) | Сначала партии с **более ранним сроком годности** (приоритет по умолчанию для фармы) |
| **FIFO** (First In — First Out) | Сначала партии с **более ранней датой производства** / поступления |

Дополнительно:

- Нельзя резервировать партии с истёкшим сроком годности.
- Желательно не резервировать партии, срок которых истекает до планируемой даты окончания производства (мягкое предупреждение).
- Учитывается только **свободный** остаток: `запас − уже зарезервировано`.
- В спецификации — **регистрация поставщиков** (компонент → одобренный контрагент). В UI подбора/просмотра/печати контрагент партии: зелёный = одобрен, жёлтый = не одобрен.
- **Аналоги:** если для материала спецификации нет годной партии, подбор предлагает прямой аналог из справочника (без цепочки A→B→C). Пользователь может сменить материал вручную. В резерве фиксируются материал спецификации и фактически отпущенный. Смешивать базовый материал и аналог в одной позиции нельзя.
- **Пересчёт по характеристикам партии:** метод «Содержание и потеря при высушивании» в строке спецификации действует, только если материалу назначено применение количественного содержания и/или потери массы при высушивании. Эталон содержания — в строке спеки; факт — регистр LCH (только поля из применения). Формулы и сценарии: `docs/LOT_RECALC.md`. Нет факта — эталон / потеря 0 % и предупреждение, резерв не блокируется. Приёмка запас не пишет в этот регистр.

## 6. Статусы заказа и материальные потоки

| Статус заказа | Действие по запасам |
|---------------|---------------------|
| **Новый** | Резервов нет; заказ можно выбрать на вкладке 1 рабочего стола |
| **Спланирован** | После подтверждения подбора сырья: резерв партий под серию; строки плана в ТЧ; стартовый факт = план |
| **Завершен** | Списание/приход и снятие резерва по **фактическим** данным (выпуск и состав); если факт не введён — по плану |
| **Отменен** | Снятие резервов, возврат доступности |

---

## 7. Маркировка и идентификация в производстве (справочно)

На всех стадиях материалы, тара, оборудование и зоны должны быть идентифицированы с указанием продукта, дозировки (где применимо) и **номера серии** (GMP ЕАЭС / EU GMP 5.12).  
В системе это отражается через обязательную связь заказа с серией и резервами партий.

---

## 8. Документирование

В записи о серии / заказе должны быть доступны:

- номер серии ГП и материал (продукт);
- номера партий и количества каждого исходного материала;
- рабочий центр, даты/время начала и окончания;
- ссылка на спецификацию (рецептуру).

Это соответствует требованиям к протоколу на серию (Batch Processing Record): фиксация номеров партий исходных материалов и фактически отвешенных количеств (PIC/S / GMP ЕАЭС, гл. 4).
