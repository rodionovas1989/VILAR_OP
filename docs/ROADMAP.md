# Дорожная карта Vilar OP

Живой документ. Обновлено: **2026-11-04** (WP11 стол кладовщика; G13; R9; A3c).  
Стабильный код: ветка **`main`**. Новые фичи — только в отдельных ветках.

**Процесс:** идея → проработка → статус **есть план** + ссылка на [`docs/plans/`](plans/) → после merge в `main` — **готово**.  
Канон планов и метрик: [plans/README.md](plans/README.md). Wiki: [roadmap-and-agent-docs](../wiki/sources/roadmap-and-agent-docs.md).

**Колонки:** ID · Тема · Описание · Приоритет (`P0`…`P3` / `—`) · План. дата (`YYYY-MM` / `—`) · Статус · План · Effort (у `готово`: часы · токены; иначе пусто).

**Статусы:** `идея` · `в работе` · `есть план` · `процесс` · `отложено` · `готово`.

---

## Срез статуса

| Слой | Оценка | Комментарий |
|------|--------|-------------|
| Функционал ОП (заказы, планирование, складские док-ты) | **пилот готов** | Основной контур в коде |
| Безопасность периметра | **пилот ок** | HTTPS, rate limit, AuthGate, SSH key-only |
| Эксплуатация | **улучшается** | Скачивание бэкапа на ПК; журнал входов; EnvironmentFile |
| Масштаб 10–15 пользователей | **осторожно да** | SQLite WAL; дальше STOR1 (таблицы) → I1 Postgres |
| Документация vs код | **процесс** | sync после main; CHANGELOG; LLM Wiki |

**Прод vs localhost:** бой — HTTPS/`vilar-prod.ru`. Локально — `localhost:5173` + `:3001`.
