## Сделано (факт в `main`)

### Продукт
- [x] Справочники, заказы на производство, рабочий стол планирования (подбор → Гант → матрица)
- [x] Складские документы по типам (RCP/TRN/INV/WOF/PST/RES/PRI/PRR/SHP), post/cancel/repost
- [x] RES ↔ `confirmMaterialPicks`; PRI+PRR+fulfill в `completeOrder` (одна транзакция)
- [x] Заказ как оркестратор (`ProductionOrderPage`), не как движение запасов
- [x] Отчёты: выпущенные серии, запасы; обратная связь; руководство пользователя
- [x] Главная + избранное per user; свой логотип/favicon (без чужого бренд-марка)

### Платформа и ИБ (пилот)
- [x] SQLite (`node:sqlite`, WAL), не JSON как источник истины
- [x] Auth: JWT, AuthGate (гости только «Вход»), RBAC на API и UI
- [x] Rate limit login; CORS; scrypt-пароли
- [x] HTTPS: nginx + Let’s Encrypt на **vilar-prod.ru**; `:3001` снаружи закрыт
- [x] SSH: только ключ, без пароля/root (шпаргалка в `local/`, не в git)
- [x] Админ: резервные копии / очистка / демо на ВМ + **скачивание слепка на компьютер пользователя**
- [x] Журнал входов (Администрирование) — успех/отказ, IP, логин
- [x] Секреты Admin в `EnvironmentFile` на ВМ (не в открытой строке unit)

### GMP (частично)
- [x] Жёстко: одна партия сырья на компонент в заказе; FEFO/FIFO; не просроченные; свободный остаток
- [x] Guards статусов заказа (`docs/ORDER_STATUS_GUARDS.md`)
- [x] Утверждённые поставщики — **мягко** (бейдж); заказчик пока не готов к жёсткому запрету
- [ ] Карантин/блокировка партии документом качества (подсветка на рабочем столе + причина) — **запланировано**
- [ ] Срок годности vs конец производства; уникальность номера серии на сервере

## Идеи класса систем (ОП / GMP / ERP-lite) — будущее

Не обязательства, а запас тем:

1. **Интеграции:** обмен с 1С/ERP (номенклатура, остатки, заказы), EDI отгрузки.
2. **Прослеживаемость:** полный genealogy партия→серия→отгрузка; электронная подпись проведения.
3. **Планирование:** конечные мощности (CRP), переналадки, календарь простоев РЦ.
4. **Качество:** COA, отклонения (deviation/CAPA), блокировка партии в резерве.
5. **Склад:** ячеистый учёт, ТСД/штрихкод, межскладские маршруты.
6. **ИБ/комплаенс:** SSO (AD/OIDC), разделение обязанностей (SoD), неизменяемый audit trail.
7. **Эксплуатация:** метрики (латентность API, длина очереди writer), алерты диска/сервиса, staging-контур.
8. **UX:** уведомления о дефиците сырья; дашборд сменного мастера; **внутренний чат** (см. C1); мобильный «только проведение».
