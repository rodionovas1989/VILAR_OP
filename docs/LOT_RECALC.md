# Пересчёт нормы по характеристикам партии

Значения вводятся **в процентах** (95 и 2, не 0,95 и 0,02). Эталон содержания в строке спецификации, если не задан, равен 100 %.

Обозначения:

- **норматив** — потребность по спецификации, кг (`норма × N / 1000`);
- **эталон** — эталон количественного содержания в строке спецификации, %;
- **содержание** — фактическое количественное содержание партии, %;
- **потеря** — фактическая потеря массы при высушивании партии, %.

В формулу входят **только характеристики из применения** материала. Спека сама по себе поля не добавляет.

## Оба коэффициента в применении

Пример: содержание 95 %, потеря 2 %, эталон 100 %:

```
расчёт = норматив × эталон × 100 / (содержание × (100 − потеря))
       = норматив × 100 × 100 / (95 × 98)
```

Это то же самое, что `норматив × (эталон / содержание) × (100 / (100 − потеря))`.

`(1 − потеря)` в знаменателе верно **только если потеря записана долей** (0,02). При вводе «2 %» нужно `(100 − 2)`, иначе формула ломается. Второе «×100» как раз переводит проценты потери в ту же шкалу.

## Только количественное содержание

Пример: содержание 95 %, эталон 100 %:

```
расчёт = норматив × эталон / содержание
       = норматив × 100 / 95
```

Потеря в формулу не входит (как если бы она была 0 %).

## Только потеря массы при высушивании

Пример: потеря 2 %:

```
расчёт = норматив × 100 / (100 − потеря)
       = норматив × 100 / 98
```

Содержание в формулу не входит (как если бы факт совпал с эталоном).

## Нет значения в регистре

Процесс не стопается. Недостающий коэффициент подставляется так:

- содержание → эталон спецификации;
- потеря → 0 %.

Показывается предупреждение. Приёмка запас в этот регистр не пишет: факт задаёт документ «Управление характеристиками».
