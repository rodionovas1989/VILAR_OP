# Changelog

Все значимые изменения проекта фиксируются здесь. Формат близок к [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Added
- Справочник **Аналоги**: шапка = базовый материал, таблица замен; опционально спецификация; двусторонняя замена без транзитивности. Подбор сырья и факт производства могут сменить материал из списка; в заказе хранятся `specLineId` / `specMaterialId`.
- **Характеристики партий** (качество): системные «Количественное содержание» и «Потеря массы при высушивании» + пользовательские; код/название/единица системных полей не меняются; применение — источник полей LCH и права включить пересчёт в спеке.
- Загрузка рецептур ВИЛАР: Админ → Данные → «Загрузить рецептуры ВИЛАР» (`RECIPES`) или `npm run import:recipes` (очистка + 14 спецификаций, Линия №1, плановые объёмы, 2 пары аналогов). Источник: `backend/scripts/customer_recipes.json`.
- В строке спецификации: стабильный `id`, метод пересчёта и эталон содержания %. Факт — документ **Управление характеристиками** (LCH). Потеря массы при высушивании — обратная величина к сухому остатку: в формуле `(100 − потеря)`. Нет факта — эталон / 0 % и предупреждение, без стопа. Методика: `docs/LOT_RECALC.md`.
- Поиск в выпадающих списках (`SearchableSelect`: поле «Поиск…» сверху, portal поверх overflow, ширина под длинные названия).
- Технологические карты (справочник) и обязательная ссылка в спецификации; миграция на 2 техкарты «Линия 1/2».
- Планирование серий: массовое создание заказов «новый» на период по существующим сериям (РЦ из техкарты).
- Отчёт «План/Факт производства» (горизонт плана vs факт выпуска).
- Сценарии качества (MVP): при создании партии — авто-документ «Управление качеством» по отборам материал/контрагент (`feature/quality-scenarios-mvp`).
- Отчёты «Качество запасов» и «История качеств» (дерево материал → партия → детали; Excel; RBAC).
- Запрет удаления справочников (материалы, партии, серии, склады, контрагенты, РЦ, спецификации, качества партий), если объект уже используется; сообщение со списком мест использования.

### Changed
- Переработка качества: справочник «Качества партий» с разрешением (Годен / Условно годен / Не годен); единый документ «Управление качеством»; регистры состояния и истории; проверки в планировании и при закрытии заказа. Нет записи в регистре → по умолчанию Годен. Старые типы QIN/QRL/QBL сняты.
- В таблице рецептуры метод пересчёта сокращён до «Содерж. / ПМПВ» (потеря массы при высушивании). Колонка «мг/табл.» убрана: в расчётах используется только кг на 1000 уп.

## [0.2.0] — 2026-08-15

### Added
- Документ качества QBL («Блокировка партии»): причина, флаг на партии, красная подсветка в планировании (резерв пока разрешён).
- httpOnly cookie-сессии (`vilar_session`) + CORS credentials; Bearer оставлен на переходный период.
- Админ-страница «Что нового» (чтение `docs/CHANGELOG.md`).
- Простой общий чат в шапке (polling).
- Helmet на Express; сниппет заголовков nginx.
- Выбор складов списания/выпуска при завершении производства.

### Changed
- `resolveActorUserId` больше не подставляет Admin при отсутствии пользователя.
- Уникальность номера серии при create/update.

### Security
- Cookie: HttpOnly, SameSite=Lax, Secure на проде.

## [0.1.0] — 2026-08-14

### Added
- Пилот на https://vilar-prod.ru (nginx + Let’s Encrypt).
- Guest AuthGate, rate limit логина, журнал входов, бэкапы с выгрузкой на ПК.
