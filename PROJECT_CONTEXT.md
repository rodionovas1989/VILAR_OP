# PROJECT_CONTEXT

## Ветка: main

После merge `feature/series-planning-tech-maps`: техкарты, планирование серий, отчёт План/Факт.

- Справочник `tech_maps` (имя + РЦ); в спецификации обязательный `techMapId`.
- Миграция: две техкарты «Линия 1/2», спецификации ~поровну.
- `POST /api/planning/plan-series` — массовое создание заказов `новый` по существующим сериям (период общий, основная спецификация, РЦ из техкарты; 1 серия → 1 незакрытый заказ; дубли серий в строках формы запрещены; «Подобрать серии»).
- UI: Планирование → Планирование серий; Отчеты → План/Факт производства (фильтр по горизонту плана).

Пилот: https://vilar-prod.ru
