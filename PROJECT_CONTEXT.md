# PROJECT_CONTEXT

## Ветка: main (эталон площадки)

Снимок перед режимом сервер-клиент: SQLite, складские документы, планирование, отчёты, обратная связь, руководство пользователя.

### В этом снимке
- SQLite, RES, completeOrder, JWT/RBAC, тесты цепочки, связи документа
- Карточка документа/заказа: блок «Дополнительно» закреплён внизу модалки
- Отборы и сортировка списков сохраняются в `localStorage` на пользователя и страницу
- Подсистема **Отчеты**: выпущенные серии; запасы (склад → материал → партия)
- Навигация: одна открытая подсистема (аккордеон)
- **Обратная связь** и **Руководство пользователя** в Администрировании

### Следующее
- Режим сервер-клиент (LAN): одна ссылка по IP сервера
- Ревью к проду: архитектура, логика, интерфейсы, уязвимости
- Сменить пароль Admin на площадке; расписание backup
- После смены API или новых объектов RBAC: `restart-all.bat` и повторный вход
