# PROJECT_CONTEXT

## Ветка: main (активна)

Актуальное состояние системы оперативного планирования ВИЛАР после слияния фич планирования и производства.

### Включено
- Справочники (материалы, спецификации с типом и регистрацией поставщиков, контрагенты, партии, серии, РЦ, склады, плановые объёмы)
- Запасы с привязкой к складу; резервы; движения
- Рабочий стол планирования (заказы → сырьё FEFO/FIFO → Гант ECharts → иерархия/печать → матрица)
- Производство: управление спланированными заказами (план/факт выпуска и состава, завершение по факту)
- Администрирование: экспорт справочников в Excel
- Норма рецептуры: кг на 1000 уп; индикация одобренных поставщиков
