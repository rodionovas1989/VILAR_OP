# PROJECT_CONTEXT

## Ветка: feature/quality-scenarios-mvp

MVP подсистемы «Сценарии» (качество):

- Тип: регистрация новых партий (`lot.create`).
- Отборы: материалы / контрагенты (`all` | `selected`; пустой selected = никто).
- Действие: создать (+ провести) QCM с заданным `qualityId`; актор = создатель партии.
- Если регистр качеств по партии уже есть — skip. Несколько матчей → несколько документов.
- Очередь / валидация / flow-конструктор — вне MVP.

База: `main`. Пилот: https://vilar-prod.ru (только после merge).
